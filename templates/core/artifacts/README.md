# Generated artifacts

This directory is reserved for generated evidence:

- `logs/` stores operational logs.
- `traces/` stores structured execution traces.
- `reports/` stores generated evaluation or verification reports.
- `benchmarks/` stores generated benchmark outputs.

Transient contents are ignored by Git. Curated baselines or reports should be promoted deliberately into an appropriate tracked location such as `evals/benchmarks/` or `docs/research/`.
