# Governance

## Maintainers

Maintainers are responsible for project direction, review quality, releases, and enforcement of contribution expectations.

## Decisions

Routine changes are decided through review. Architectural or compatibility-sensitive changes should be documented under `docs/decisions/` before implementation when the decision would be costly to reverse.

## Becoming a maintainer

Sustained, high-quality contribution and review are prerequisites. Existing maintainers should document any project-specific nomination or approval process here as the project grows.
